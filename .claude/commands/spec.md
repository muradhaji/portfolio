Draft a spec change for: $ARGUMENTS

1. Read `specs/README.md` and every spec the change touches.
2. Update the relevant spec (or create a new one from the template in `specs/README.md` and add it to the table there). Mark each new or changed behavior with `(proposed)` and give it the next free ID and a `[test]` or `[manual]` tag.
3. List anything unclear under "Open questions" instead of guessing.
4. Do not change code or tests.
5. Show me the proposed behaviors and open questions, and ask me to approve or edit them.
